04 — MOTION, ACCESS, LOADING

MOTION EXPLAINS SPACEEarth zoom, roof removal, zone illumination, route drawing, camera moves into a zone. Ease cubic-bezier(.2,.7,.2,1), 400–1000 ms. No decorative loops. Reduced motion swaps camera moves for cuts.
ACCESSIBLE BY DEFAULT4.5:1 text contrast. Status uses icon and word. Every map has a list alternative. Captions and transcripts on all video. 44 px touch targets. Keyboard: Tab order follows reading order, Esc closes drawers, ⌘K opens search.
PROGRESSIVE LOADINGPage shell → Earth → Yashobhoomi assets → Hall 2 model → zone detail → stall model on demand. Mobile gets the 2D plan first and 3D on request.
